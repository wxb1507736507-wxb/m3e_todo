# M3E Todo

一款备忘录、待办与课表软件，专注于自由记录、任务拆解和「一眼看清今天要做什么」。
Material 3 Expressive 风格，手机优先（Android），也能构建 Windows 与 Web 版本。

---

## ✨ 核心功能

### 📝 待办与记录

- **多级子任务**：编辑待办时添加子选项，把复杂事项拆成可勾选的步进任务
- **分类条**：一行的紧凑分类条，点一下切换、长按管理；进入分类可单独搜索
- **日历回顾**：左右滑动翻月，查看历史待办记录，支持日期跳转与关键词搜索
- **随笔**：在日历当天的位置随手记录，可插入图片、视频、文件与录音
- **纪念日**：生日、纪念日、倒数日自动标在日历上并倒数（还有 18 天 / 30 岁 / 第 6 年）
- **多媒体附件**：图片（相册选择）、视频、文档、语音备忘

### 🔔 提醒

- 待办到期当天上午 9:00 提醒，可提前一周 / 三天 / 一天 / 当天
- 每条待办可单独选择响铃或仅消息，也能各自挑选铃声
- 习惯按星期与时间单独提醒；纪念日同样会提醒

### ✅ 习惯打卡

- 习惯竖向排列，点圆环打卡，点其他位置进入整理页
- **打卡小组件**：桌面上一眼看到今天要打的项目，**只有圆环会改变状态**，点别处不会误改记录
- 整理页可勾选这个小组件显示哪几个习惯，铅笔进入 App 编辑

### 🎓 课程表

- 周视图课表：左侧节次与上下课时间，右侧一~日课程块，跨两节的课按合并格绘制
- **左右滑动切换周**（也可以点表头箭头），切换时整块课表像翻页一样整体滑动
- **点空白格出「＋」**，点「＋」才在该格新建课程；**点课程弹「课程详情」**（教室、老师、每次上课时间与周数），再点「编辑」进表单
- 新建课程：单节课、手动填课表两条路；编辑器含课程名（必填）、教室（非必填）、备注（如老师）、时段（加减次数 + 滚轮选星期与节次）、上课周数、课程背景色
- **学期设置**：学期名、开学第一周的周一、总周数、每节课时间、**周末有课**、**显示非本周课程**
- **背景可自定义**：课程表页面背景、课程背景、桌面小组件背景，都能选图 / 换图 / 裁剪 / 移除，并可调「遮罩浓度」让文字不被图压住
- **课程表小组件**：桌面上按天显示（`今天 · 周二 9/15`），左右箭头可看前一天 / 后一天，**全程不用打开 App**
- 课表列表页：一屏看完全部课程

### 🧩 桌面小组件

- 打卡小组件、课程表小组件，共用一套背景设置
- 小组件在 App 从未启动时也能显示上次同步的内容；点击即可进入对应页面

### 🎨 个性化

- 主题色、深浅模式；待办可设色块色与字体色，内置常用色 + 调色板 + 从图片取色
- 应用背景、课程表背景、小组件背景三处独立设置，各自带透明度
- **课程表按「纸」来呈现**：没设背景图时是纯白底配深色字（即使系统是深色模式），因为小字课表在白纸黑字下最好认

### 📱 平台

- **Android**：主平台，含小组件、提醒、附件、语音备忘
- **Windows / Web**：同一套代码可构建（CI 会一并产出），小组件与系统级提醒只在 Android 生效

## 🎯 设计理念

希望记录这件事足够轻盈自由，像随手书写的笔迹一样飘逸灵动。不做臃肿繁杂的功能，聚焦任务拆解、自由记录，以及课堂上真正要回答的那个问题：下一节在哪。

## ⚠️ 已知不足

- **不接入系统日历**：课程与待办都只存在于本应用内，不会写进手机日历，也不与任何账号同步；换机需自行备份
- **课程没有单独提醒**：提醒能力目前给了待办、习惯与纪念日，课程到点不会提醒
- **小组件内容依赖 App 至少同步过一次**：课表数据由 App 计算后交给小组件（含前后约 5 周的每一天），长时间不打开 App 时小组件可能停留在旧数据
- **小组件的「滑动」是单向的**：平台在切页时会把旧页立刻隐藏，所以看到的是新的一天滑入，而不是两页同时滑动
- **无云端备份 / 多设备同步**：数据是应用私有目录里的 JSON 文件，没有账号体系，也没有加密
- **课表规则有限**：单双周用「周次集合」表达，够用但不能表达「某周临时调课」；课程冲突只在编辑时提示，不会自动排解
- **拍照导入课表已移除**：识别准确率不达标（真机实测对真实课表还原不佳），已整块删除，包括本地 OCR 与网络识别两条路
- **发布签名**：CI 未配置签名密钥时，产出的 APK 使用 debug 签名，可侧载安装但不能上架
- **Windows / Web 版本未在真机验证**：本仓库的验证集中在 Android 真机；Windows/Web 仅保证能构建
