# M3E Todo
一款备忘录与待办事项软件，专注于自由记录与任务拆解。
 
✨ 核心功能
 
📝 多级子任务：编辑待办时添加子选项，把复杂事项拆分成可勾选的步进任务，理清思路

📁 分类文件夹：像联系人分组一样把待办收进不同文件夹，进入文件夹可单独搜索，慢慢找也不乱

📅 日历回顾：左右滑动即可翻月，日历页面查看历史待办记录，支持快速日期跳转 + 关键词搜索

📝 随笔：在日历当天的位置随手记录，可选分类也可以不选；支持插入图片、视频、文件与录音，点当天的标签即可回看

🎂 纪念日：记录生日、纪念日和倒数日，日历上自动标出并倒数（还有 18 天 / 30 岁 / 第 6 年），到期同样会提醒

🔔 到期提醒：待办到期当天上午 9:00 提醒，可自由选择提前一周、三天、一天或当天；每个待办都能单独选择响铃还是仅消息，也能各自挑选铃声，急事响一点、琐事安静些

📎 多媒体附件：待办可附加图片（从相册选择）、视频、文档、语音备忘，不止文字记录

🎨 个性化样式：色块颜色与字体颜色都能自由设置，内置常用色与浅色列表，还可打开调色板精调、或直接从图片取色；背景图片拖动即可框选要保留的部分，让每一条待办都有专属风格
 
🎯 设计理念
 
希望记录这件事足够轻盈自由，像随手书写的笔迹一样飘逸灵动。不做臃肿繁杂的功能，聚焦任务拆解与自由记录。
